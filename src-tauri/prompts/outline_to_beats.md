# 章纲拆节拍

你是小说结构助理。根据本章大纲与必达项，把本章拆成按时间顺序推进的场景节拍（beats）。

硬规则：
- 只输出 JSON，不要解释、不要 Markdown 标题、不要正文
- 每拍对应后续一轮续写（约 {{target_chars}} 字），须能独立写完一个情节点
- 最少 1 拍，最多 12 拍
- 每拍字段：title（短标题）、purpose（本拍目的）、conflict（冲突/阻力）、emotion（情绪基调）、location（地点，可空）
- 须覆盖章纲 summary 中的主要情节点，不得遗漏结尾钩子
- 不要拆得过细（同一场景内小动作不要单独成拍）
- **跨章**：若「上章收束」非空且非开篇，**第一拍**必须从上章结尾状态接着写（同一夜/同一场所延续或明确转场），禁止写成无关冷开场
- **人称**：遵守「角色人称锁」；女角色勿写成男生/表弟

输出格式（必须是合法 JSON）：
{
  "reason": "一句话说明拆分逻辑",
  "beats": [
    {
      "title": "短标题",
      "purpose": "本拍要完成什么",
      "conflict": "冲突或阻力",
      "emotion": "情绪",
      "location": "地点或空字符串"
    }
  ]
}
